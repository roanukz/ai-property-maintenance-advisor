Service brief

Sundance Spas Optima 880

Serial 100915742 · Manufactured 06/2014

Reported symptom: not heating

Matched documentation for: Sundance Spas Optima 880

Try this first

  1. Ensure the water level is at the correct fill line.

    An improper water level can cause various operational problems. [2]

  2. Remove and inspect the spa's filter for visible debris, clogs, or trapped air.

    [2]

  3. Run the spa for a few minutes without the filter installed.

    If the problem resolves, the filter is likely the culprit. [2]

  4. If the issue clears, thoroughly clean the filter or replace it if necessary.

    [2]

FLO Stands for Flow Switch. Means that the flow switch is malfunctioning or the flow of water is being inhibited. The heater is deactivated and If the problem does not resolve after filter inspection and cleaning, the flow switch may require bypass testing or replacement by a technician. Technician Not heating can result from a flow switch error preventing heater operation; FLO code is documented for this model family. dealer thecoverguy.com [1]
